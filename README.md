## Getting Started

### Prerequisites
- [Bun](https://bun.sh/) (recommended) or Node.js (v18+)

### Installation
```bash
bun install
```

### Development
```bash
bun run dev
```

### Tests & Quality
```bash
bun run lint
bun run test
bun run test:seo
```

### Production Build
```bash
bun run build
```
Emits statically prerendered routes to `dist/` with full HTML, JSON-LD structured data, and meta tags.
